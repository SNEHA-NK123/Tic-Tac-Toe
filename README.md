# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using HTML, CSS, and JavaScript. This project allows two players to play against each other on a 3 × 3 grid. The game automatically detects the winner or a draw and provides an option to restart the game.

## ✨ Features

* 🎮 **Two-Player Game:** Play with two players, X and O.
* 🏆 **Winner Detection:** Automatically detects when a player wins.
* 🤝 **Draw Detection:** Identifies when the game ends in a draw.
* 🔄 **Reset Button:** Restart the game at any time.
* 🎨 **Simple UI:** Clean and user-friendly interface.
* ⚡ **Interactive Gameplay:** Click on any empty square to make a move.
* 🔁 **Automatic Turn Switching:** Players take turns automatically.

## 🛠️ Technologies Used

* **HTML5** – Structures the game board and user interface.
* **CSS3** – Styles the game board, buttons, and layout.
* **JavaScript** – Implements game logic, player turns, winner detection, and reset functionality.

   ```bash

   ```

2. Open the project folder in VS Code.

3. Make sure all three files are in the same folder:

   * `index.html`
   * `TicTacToe.css`

4. Open `index.html` in your browser.

5. Start playing!

You can also use the **Live Server** extension in VS Code to run the project.

## 🎯 How to Play

1. The game starts with Player X.
2. Player X clicks on an empty square.
3. Player O takes the next turn.
4. Players continue taking turns until one player gets three marks in a row, column, or diagonal.
5. The game announces the winner.
6. If all nine squares are filled without a winner, the game ends in a draw.
7. Click the **Reset** button to start a new game.

## 🏆 Winning Conditions

A player wins by placing three identical marks in any of the following combinations:

* Three horizontal rows
* Three vertical columns
* Two diagonal lines
